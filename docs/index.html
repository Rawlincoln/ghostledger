Run the full app in the browser

GitHub Codespaces starts a cloud computer with Node 22. After it boots, in the terminal:

  1. Wait for npm install to finish (it runs on first open).
  2. Run npm run dev.
  3. Open the forwarded port 8080 — that is GhostLedger.
